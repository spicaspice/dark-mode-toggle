# Dark Mode Toggle Chrome Extension

シンプルで使いやすいダークモード切り替えChrome拡張機能です。

## インストール方法

### 方法1: .crxファイルを使用（推奨）

1. Chromeで chrome://extensions/ を開く
2. 右上の「デベロッパーモード」をONにする
3. dark-mode-toggle.crxファイルをChromeにドラッグ&ドロップ
4. インストール確認ダイアログで「追加」をクリック

### 方法2: 開発者向けインストール

1. このフォルダ内のファイルをすべて保存
2. Chromeで chrome://extensions/ を開く
3. 右上の「デベロッパーモード」をONにする
4. 「パッケージ化されていない拡張機能を読み込む」をクリック
5. このフォルダを選択

## 使用方法

1. 任意のウェブページを開く
2. 拡張機能のアイコンをクリック
3. 「Enable Dark Mode」ボタンをクリック
4. ページがダークモードに切り替わります
5. 再度クリックすると通常モードに戻ります

## ファイル構成

- manifest.json: 拡張機能の設定
- popup.html: ポップアップ画面
- popup.js: ポップアップの動作制御
- content.js: ページへのCSS注入
- styles.css: ポップアップのスタイル
- icon16.png, icon48.png, icon128.png: アイコンファイル
- dark-mode-toggle.crx: パッケージ化された拡張機能
- dark-mode-toggle.pem: 秘密鍵ファイル（更新時に必要）

## 注意事項

- .crxファイルはデベロッパーモードが有効なChromeでのみインストール可能
- インストール時にセキュリティ警告が表示される（正常な動作）
- ページごとの設定が自動保存されます

## トラブルシューティング

- 拡張機能が動作しない: ページをリロードしてください
- インストールできない: デベロッパーモードがONになっているか確認してください
